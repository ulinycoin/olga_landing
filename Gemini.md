# Проект: Опросник Нутрициолога (Olga Nutrition)

Этот файл содержит техническую информацию о проекте для будущих этапов разработки.

## 📋 Обзор проекта
Лендинг с двумя типами опросников (взрослый и детский) для сбора медицинского анамнеза. Данные сохраняются в облаке Netlify и доступны через защищенную админ-панель.

## 🛠 Технологический стек
- **Frontend**: React + Vite, Vanilla CSS.
- **Анимации**: Framer Motion.
- **Иконки**: Lucide React.
- **Backend**: Netlify Functions (Node.js).
- **Хранение данных**: Netlify Forms API.
- **Экспорт**: jsPDF + jspdf-autotable (с поддержкой кириллицы через кастомный шрифт Arial).

## 📁 Структура проекта
- `src/components/`:
  - `SurveyWizard.jsx`: Логика проведения опроса (пагинация, сохранение прогресса).
  - `AdminDashboard.jsx`: Панель управления (просмотр, экспорт в PDF, удаление).
- `src/data/surveys.js`: Определение всех вопросов и категорий.
- `netlify/functions/get-submissions.js`: Прокси-функция для безопасного доступа к API Netlify (получение и удаление данных).
- `index.html`: Содержит скрытую форму для корректного обнаружения полей Netlify.

## ⚙️ Переменные окружения (Netlify Env Vars)
Для работы админки в Netlify должны быть настроены следующие переменные:
- `NETLIFY_AUTH_TOKEN`: Personal Access Token для доступа к API.
- `NETLIFY_SITE_ID`: ID сайта в системе Netlify.
- `ADMIN_PASSWORD`: Пароль для доступа к разделу `/#admin`.

## 🚀 Основные возможности
1. **Двойной опросник**: Поддержка разных наборов вопросов для взрослых (q1-q36) и детей (q101-q132).
2. **Экспорт в PDF**: Генерация детализированных отчетов на русском языке.
3. **Облачное хранение**: Данные не привязаны к устройству и доступны администратору с любого ПК.
4. **Удаление**: Реализовано полное удаление анкет из облака через интерфейс админки.
